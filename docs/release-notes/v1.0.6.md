# CodexSwitch 1.0.6

## What's new

- Keep account sessions and quota snapshots current automatically. While
  CodexSwitch is running, eligible accounts refresh every six hours; launch
  and wake refresh only profiles whose last successful snapshot is stale.

## Improved

- Keep long account emails and the Pro plan label on one line. Email labels
  now truncate in the middle instead of squeezing the plan into multiple rows.
- Scheduled refreshes reuse the existing managed Codex sign-in path, never
  overlap a manual refresh, and skip accounts that require browser sign-in.

## Download

Install the signed and notarized `CodexSwitch-1.0.6.dmg`, or use the matching
ZIP archive. `SHA256SUMS.txt` and `release-manifest.json` are included for
verification.
