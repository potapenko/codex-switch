# CodexSwitch 1.0.7

## What's new

- Account rows now use compact, system-adaptive cards with a clearer visual
  hierarchy for identity, quota, reset time, reset credits, and freshness.
- Removing an account now requires explicit confirmation and explains that
  only the local CodexSwitch entry and cached quota data are removed.

## Improved

- The popover now follows the measured height of its visible account cards,
  avoids blank space after the final row, and remains bounded by the current
  display when content grows.
- Quota status is easier to scan with a small progress ring while the existing
  percentage text and availability colours remain authoritative.

## Download

Install the signed and notarized `CodexSwitch-1.0.7.dmg`, or use the matching
ZIP archive. `SHA256SUMS.txt` and `release-manifest.json` are included for
verification.
