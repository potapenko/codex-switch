# CodexSwitch 1.0.5

## What's new

- Reauthenticate an expired Codex account directly from its existing row with
  a clear **Sign in again** flow. Cached quota data stays visible while the
  account waits for a new browser sign-in.
- See one stable refresh indicator for the whole dashboard. Account rows keep
  their content and positions while CodexSwitch refreshes every profile.
- Fit more accounts on screen. The popover now grows to the available height
  of the current display and scrolls only when the account list truly needs it.

## Improved

- Made sign-in recovery easier to notice with a dedicated SwiftUI callout and
  an intrinsic-width action beside the explanation.
- Kept long account labels and retry/remove actions on one line so changing
  account states no longer causes distracting layout jumps.

## Download

Install the signed and notarized `CodexSwitch-1.0.5.dmg`, or use the matching
ZIP archive. `SHA256SUMS.txt` and `release-manifest.json` are included for
verification.
